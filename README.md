# Ransom

A mobile-first playable version of the Ransom solo card game.

## Play

Open `index.html` in a browser or publish the repository with GitHub Pages.

The game uses a standard 54-card deck and implements the Standard three-run mode, including:

- burn-before-draw turns
- swipe-to-discard interaction
- Royal Flush, Four of a Kind and All the Keys outs
- 2 and 5 trap cards
- Black Joker hand destruction
- Red Joker burn-pile recovery
- Red/Black Joker cancellation

On desktop, cards can also be dragged with a mouse (or double-clicked to discard).
